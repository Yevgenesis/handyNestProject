# Правила работы с Next.js

В проекте используется Next.js 16 с изменениями API и структуры относительно старых версий.

Перед изменением framework-specific кода прочитайте соответствующую документацию в `node_modules/next/dist/docs/`, учитывайте deprecation warnings и не переносите устаревшие паттерны из Pages Router.
